# Глосарій дизайну: як називати і які параметри передавати

Запит складається з трьох частин: **тип** (що робимо, з design-types), **стиль** (уся візуальна мова),
**патерни** (частини сторінки) і **параметри** (налаштування стилю чи патерна). Назви пишуться
латиницею, як у таблицях нижче; параметри у форматі `назва=значення`.

Шаблон запиту:

> Зроби **{тип}** у стилі **{стиль}**, патерни: **{патерн}, {патерн}**; параметри: **{назва=значення}**.

Чого не назвали, береться за замовчуванням, і агент перед роботою повторить повний набір одним рядком.

## Стилі

| Назва | Українською | Коротко | Головні параметри (за замовчуванням) |
|---|---|---|---|
| `canvas-light` | Робоче полотно | Стиль сайту XBrain: світлий, як вікно продукту; великі кольорові поля, дуже великий текст великими літерами, один об'єкт посередині, який збирає скрол-сцена; рамки, ручки й піни дизайн-канвасу як оздоблення сторінки; рука з часток на вирішальному кроці | `accent` (лавандовий #5f57b3), `fields` (lav, sky, mint, sand, rose), `display` (Inter Tight), `object` (картка задачі), `stages` (7), `canvas-chrome` (on), `particle-object` (hand), `motion` (scroll) |
| `paper-editorial` | Папір | Довге читання на теплому папері, засічковий шрифт, примітки збоку | `paper` (warm), `accent` (oxblood), `columns` (2), `dropcap` (on) |
| `dark-console` | Консоль | Інструмент розробника вночі: моношрифт, термінал, що друкує сам | `signal` (green), `scanlines` (off), `typing-speed` |
| `swiss-grid` | Сітка | Сувора модульна сітка, один гротеск, червоний акцент | `columns` (12), `accent` (red), `rules` (on) |
| `soft-gradient` | М'який градієнт | Дружній SaaS: пастельний градієнт, скляні картки | `mesh`, `glass` (on), `radius` (xl) |
| `brutal-mono` | Брутал | Гучно й сиро: товсті рамки, кислотний колір, біжучий рядок | `acid` (#d4ff00), `border` (2px), `marquee` (on) |
| `product-pedestal` | П'єдестал | Продукт як предмет у темній кімнаті, обертається на скролі | `room` (dark), `object` (window), `turn` |
| `playful-blocks` | Кубики | Яскраві округлі блоки, наліпки, пружні рухи | `palette`, `shapes`, `bounce` (0.4) |
| `data-dense` | Щільні дані | Живий дашборд, цифри, графіки з таблицями | `series`, `density` (regular), `theme` (light) |
| `cinematic-scroll` | Кіно | Фільм на скролі: камера, 3D, частки, кадри | `shots` (6), `camera` (dolly), `particles` (on) |

## Патерни

### Перший екран

| Назва | Що це | Параметри |
|---|---|---|
| `window-drawing` | Креслення вікна продукту, лінії малюються самі, лінія сканування і перехрестя | `scan`, `crosshair`, `image` |
| `object-hero` | Один об'єкт продукту великим посередині, обіцянка над ним | `object`, `tilt`, `actions` |
| `statement-hero` | Одне велике речення без картинки, одне слово в акценті | `accent-word`, `case` |
| `split-hero` | Текст ліворуч, продукт праворуч | `ratio` |

### Історія і сцени

| Назва | Що це | Параметри |
|---|---|---|
| `story-track` | Закріплена сцена на кілька екранів, скрол як камера, етапи по черзі | `stages` (7), `damp` (0.11) |
| `assembly-card` | Картка посередині, частини прилітають і стають на місце | `parts`, `object` |
| `weak-spots` | Панель «що вже закрито»: проблеми закриваються з етапами | `items`, `close-at` |
| `action-feed` | Стрічка «хто що зробив», росте з етапами | `max` (5) |
| `particle-object` | Об'єкт зі світлих часток (рука) на вирішальному кроці: збирається, тримає, розсипається | `source` (picture), `count`, `act` (grip-and-carry) |
| `colour-fields` | Кожен розділ на своєму кольоровому полі | `fields`, `transition` |
| `corner-labels` | Назва розділу в лівому куті, номер у правому, моношрифтом | `left`, `right` |

### Блоки змісту

| Назва | Що це | Параметри |
|---|---|---|
| `giant-statement` | Дуже великий заголовок, слова підсвічуються під час скролу | `light-up`, `align` |
| `receding-list` | Рядки «сходами» з чергуванням боків | `ladder`, `step` |
| `stat-tiles` | Три виміряні цифри на кольорових плитках, що лічать угору | `tiles` (3), `count-up`, `method` |
| `layer-stack` | Альтернативи як шари, що складаються в один блок | `layers`, `fold` |
| `compare-table` | Три способи роботи поруч, наш стовпець виділено | `columns`, `highlight` |
| `feature-grid` | Сітка функцій | `columns`, `icons` |
| `board-drawing` | Канбан, намальований компонентами продукту, в рамці канвасу | `columns`, `cards` |
| `bars-drawing` | Стовпчики прогресу людей і агентів з прихованою таблицею | `rows`, `legend`, `note` |
| `faq` | Питання, що розгортаються | `items` |
| `access-form` | Одне поле пошти, згода, помилки з підказкою | `endpoint`, `subject` |
| `logo-strip`, `testimonial-wall`, `pricing-table`, `timeline`, `bento-grid`, `before-after` | Звичні блоки, просто за назвою | за design-types |

### Оздоблення і навігація

| Назва | Що це | Параметри |
|---|---|---|
| `floating-header` | Шапка, що пливе з відступом від країв | `width` |
| `floating-cta` | Одна кнопка дії, що пливе внизу після першого екрана | `after`, `label` |
| `canvas-frame` | Елемент як виділений шар дизайну: назва, рамка з вісьмома ручками, бейдж справжнього розміру, рожевий вимір відступу, червона напрямна | `name`, `measure`, `guide` |
| `scroll-rail` | Власний скролбар сторінки: рамка виділення з ручками і %, піни розділів, ручки етапів | `marks`, `badge`, `logo` |
| `outline-wordmark` | Назва бренду великими контурними літерами в рамці канвасу | `fill-on-hover` |
| `under-the-hood` | Рядок «Під капотом» під кожним етапом: які скіли й хуки це роблять | `prefix`, `wide-only` |

## Спільні параметри

| Параметр | Значення | Що змінює |
|---|---|---|
| `theme` | light, dark | світла чи темна тема (не кожен стиль має обидві) |
| `accent` | колір (hex або назва) | один акцентний колір; текст ним має 4.5:1 |
| `display` | шрифт з кирилицею | шрифт заголовків |
| `motion` | scroll, calm, none | рух від скролу, спокійний або без руху (з reduced motion завжди без) |
| `density` | compact, regular, airy | щільність відступів |
| `langs` | uk, en, … | мови тексту |
| `widths` | 1440, 390, 360 | ширини для знімків перевірки |

## Приклади запитів

- «Зроби лендінг у стилі `canvas-light`, патерни: `window-drawing`, `story-track`, `assembly-card`,
  `stat-tiles`, `faq`, `access-form`; параметри: `accent=#2f7d6b`, `object=рахунок`, `stages=5`.»
- «Сторінку продукту в стилі `canvas-light` без руки: `particle-object=none`, `motion=calm`.»
- «Документацію в стилі `paper-editorial`, `columns=2`, патерн `faq` у кінці.»
- «Анонс релізу в стилі `cinematic-scroll`, `shots=5`, `particles=on`, потім `floating-cta`.»
- «Дашборд-лендінг у стилі `data-dense`, `theme=dark`, патерни `stat-tiles`, `bars-drawing`.»
- «Сторінку команд у стилі `canvas-light` з патернами `board-drawing` і `bars-drawing`» (так зроблено
  сторінки «Команди» і «Прогрес» на сайті XBrain).

## Дизайни в брейні XBrain: як просити

Ці скіли тепер у цьому ж плагіні. Дизайн живе в брейні (`Designs/`), має сторінки, шари й версії;
агент не перезаписує чужий дизайн, а додає нову версію.

| Що сказати | Що станеться | Скіл |
|---|---|---|
| «Зроби дизайн …», «намалюй макет у брейні», «зроби прототип екрану» | Новий дизайн у брейні: сторінки потрібних ширин, шари з іменами | `brain-design` |
| «Продовж дизайн …», «онови дизайн», «додай екран» | Нова версія того самого дизайну, попередня лишається в історії | `brain-design` |
| «Покажи дизайни проєкту» | Список дизайнів проєкту і задачі, пов'язані з їхніми сторінками | `brain-design` |
| «Зверстай екран у дизайні», «імпортуй HTML у дизайн», «додай стан hover», «зроби компонент» | HTML-екран чи шар у дизайні, стани, токени, компоненти | `brain-design-html` |
| «Зроби за дизайном», «як у макеті», «звір з дизайном» | Код продукту з дизайну; задача прив'язується до сторінок, кожна позначається зробленою з комітом | `brain-design-build` |
| «Виправ коментарі до дизайну», «що прокоментували» | Коментарі як черга: виправлення новою версією і відповідь у треді | `brain-design-comments` |
| «Перевір дизайн», «що не так з екранами», «доопрацюй дизайн» | Сторінки знімаються в браузері, дефекти верстки й логіки, виправлення однією версією | `brain-design-visual-qa` |
| «Синхронізуй дизайни», «експортуй у Claude Design», «перенеси дизайн в інший брейн» | Синхронізація з полотнами Claude Design, експорт папкою, файл `.xcanvas` | `brain-design-sync` |

Слова, які варто знати:

| Слово | Значення |
|---|---|
| Дизайн | Запис у `Designs/` брейну: сторінки, версії, коментарі |
| Сторінка | Один екран або кадр дизайну на полотні, зі своєю шириною |
| Шар | Частина сторінки з ім'ям (кнопка, картка, заголовок); на шар можна послатися з задачі |
| Версія | Знімок дизайну; нова зміна завжди нова версія, стару видно в історії |
| Ширини | Набір ширин сторінки для перевірки (1440, 390, 360) |
| Зв'язок з задачею | Задача знає, які сторінки вона будує; зроблена сторінка позначається з комітом |
| Артбук | Готова HTML-сторінка для читання й пересилання (звіт, презентація), не полотно екранів |

Стиль і патерни з цього глосарію можна передати і в дизайн у брейні: «Зроби дизайн лендінгу в брейні
у стилі `canvas-light`, патерни `story-track`, `stat-tiles`».
